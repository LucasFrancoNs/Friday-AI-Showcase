# Contributing

Friday-AI-Showcase is currently a portfolio-oriented public repository.

Small fixes, documentation improvements, tests, and UI refinements are welcome through pull requests.

Please keep contributions:
- free of credentials, tokens, cookies, personal data, or private integrations;
- limited to the public showcase surface;
- deterministic and dependency-light where practical;
- accompanied by tests when behavior changes.

For larger architectural ideas, open an issue first so the public/private boundary remains clear.
